# ドキュメントの文体・表記ルール
Notes配下などのMarkdownドキュメントを書く際に守る、文体・表記のルール。

## ルール
- 英数字・コード片と日本語の境界に半角スペースを入れない
    - 例：`compile_commands.jsonが置かれているディレクトリ`（○）
    - 例：`compile_commands.json が置かれているディレクトリ`（×）
    - コードブロック内や英語のみの段落は通常どおり半角スペースを使用
- `**`による強調（太字）を使わない
- 記号は前後の文字幅に合わせる
    - 日本語（全角）の文中では、読点・句点・括弧・コロンも全角（、。（）：）を用いる
    - 英語やコードのみの文脈では半角（, . ( ) :）を用いる
- 見出し（`#`や`##`）の直後に空行を入れず、次の行から本文を始める
- 1行につき1文を基本とし、句点（。）のたびに改行する
